# VuelosPúblicos (`vuelospublicos.evegat.cl`)

Radar Táctico y Scrollytelling del Gasto en Pasajes Aéreos y Misiones Oficiales del Estado de Chile.

## Características

- **Consola Táctica Retro**: Interfaz inspirada en salas de mando de guerra fría / juegos de estrategia territorial (WarGames / DEFCON / Ataque).
- **Proyección Geodésica en Canvas 2D / WebGL**: Rutas de vuelo animadas con aviones en tránsito entre Santiago (SCL) y destinos nacionales e internacionales.
- **Diferenciación por Cabina**: Alerta visual para vuelos en clase Business / Primera vs. Turista.
- **Controles Físicos Analógicos**: Perillas giratorias de escala/zoom y azimut, e interruptor de palanca metálica para aislar vuelos de alto costo.
- **Tribunal Ciudadano**: Módulo interactivo de votación para evaluar si cada viaje oficial se justifica con fondos públicos o constituye derroche.
